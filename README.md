# Online-Banking-System-Python

**Task Description:**
Implement an Online Banking System using Python, incorporating Object-Oriented
Programming (OOP) principles for the backend logic, and PyQt or tkinter for the frontend interface.

**Backend Development:**
Design classes for various components: Account, Customer, Transaction, etc.
Implement methods for functionalities: create accounts, deposit funds, withdraw funds, transfer
funds, etc.
Ensure adherence to data encapsulation, inheritance, and polymorphism principles.

**Frontend Development with PyQt or tkinter:**
Design user-friendly interface for account login, balance checking, fund transfers, etc.
Develop forms/widgets for user input validation and error handling.
Integrate backend functionalities with the frontend interface seamlessly.
